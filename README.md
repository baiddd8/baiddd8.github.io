# baiddd8.github.io

Galerie de mes apps, publiée avec GitHub Pages : https://baiddd8.github.io/

- `/` : la galerie (une carte par app)
- `/creux/` : Creux, et `/creux/confidentialite/` sa politique de confidentialité

Pour ajouter une app : un dossier `/<app>/index.html` (copier `creux/`) et une carte dans `index.html`.
